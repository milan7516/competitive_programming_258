## Program 1 — University Attendance Analysis

A university stores the attendance percentage of N students in an array. Write a program to:

1. Count the number of students whose attendance is below a given threshold.
2. Identify the student with the lowest attendance and display their position.
3. Calculate and display the average attendance of all students.

## Program 2 — Hospital Emergency Monitoring

A hospital records the number of patients arriving in its emergency department during N consecutive hours. Write a program to:

1. Find the maximum number of patients and the hour when it occurred.
2. Find the minimum number of patients.
3. Identify the peak hour.
4. Count the number of hours whose patient count is above the average.

## Program 3 — Student Name Search

A university maintains a list of N student names. Write a program to search for a given student name and display their position. The program should support:

1. Case-sensitive search — `"Priya"` and `"priya"` are treated as different names.
2. Case-insensitive search — `"Priya"` and `"priya"` are treated as the same name.

## Program 4 — Library Book Code Validator

A university library assigns each book a unique code in the format `AAA-YYYY-NNN`. Write a program to determine whether a given book code follows the required format, including:

1. Exactly 3 uppercase letters.
2. A hyphen after the first 3 letters.
3. Exactly 4 digits representing the year.
4. A hyphen after the 4 digits.
5. Exactly 3 digits representing the book number.
6. The code must have the exact required length.

---

## Program 5 — E-Commerce Product Price Sorting

An e-commerce company has a list of N product prices. Write a program to:

1. Read the product prices into an array.
2. Arrange the product prices from lowest to highest.
3. Display the sorted product prices in ascending order.
